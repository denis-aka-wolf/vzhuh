# Вжух (Vzhuh)

**Вжух** — проект с открытым исходным кодом для удалённого администрирования рабочих станций Windows. Цель проекта — подключать устройства напрямую, без обязательного облачного сервиса или стороннего узла-посредника: по локальной сети или по внешнему адресу `IP:порт`.

Для будущих подключений предусматриваются варианты аутентификации: учётная запись приложения, учётная запись Windows и дополнительная двухфакторная проверка через SMS, электронную почту или Telegram-бота.

> **Состояние проекта:** текущая демонстрация принимает соединения только через `127.0.0.1`, то есть между экземплярами приложения на одном компьютере. Входящий запрос требует явного подтверждения. Передачи экрана, управления мышью/клавиатурой, аутентификации и шифрования пока нет.

## Текущая основа

Клиентская оболочка написана на Flutter/Dart. В репозитории есть платформенные проекты Flutter для Windows, Android, iOS, Linux, macOS и Web, но наличие шаблонов не означает, что продукт поддерживает эти платформы. Целевая управляемая станция — Windows; состав платформ для операторского приложения ещё предстоит определить.

## Запуск MVP

Требуется установленный Flutter SDK. Из корня репозитория:

```powershell
.\scripts\run-debug.ps1
```

Скрипт восстанавливает зависимости и запускает приложение для Windows в режиме debug. Для ручного запуска также можно использовать `flutter run --debug -d windows`.

## Release-сборка для Windows

Из корня репозитория выполните:

```powershell
.\scripts\deploy-production.ps1
```

Скрипт выполняет `flutter analyze`, `flutter test` и сборку Windows Release, затем копирует полный каталог приложения в новый каталог `out\Vzhuh-<версия>-<время>`. Для запуска переносите каталог целиком, не только `vzhuh.exe`. Существующие каталоги результата не перезаписываются.

Несмотря на имя скрипта, текущая демонстрация не предназначена для удалённого доступа: сетевой протокол не шифруется и не аутентифицирует стороны. Соединения ограничены `127.0.0.1`.

Для ручных проверок:

```powershell
flutter analyze
flutter test
```

Инструкции по разработке и сборке — в [docs/development.md](docs/development.md).

## Важное замечание о подключении

**Это локальная демонстрация, не средство удалённого доступа.** Сервис привязан к `127.0.0.1`; протокол не шифруется и не аутентифицирует сторону. Экран и ввод не передаются. Не ослабляйте loopback-ограничение и не передавайте через соединение секретные данные. Требования к дальнейшей разработке — в [документации безопасности](docs/security.md).
