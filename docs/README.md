# Документация Вжух

Документы описывают целевой проект и требования. Они не являются подтверждением реализованного поведения: текущая версия репозитория — стартовый Flutter-шаблон.

## Разделы

- [Назначение, область применения и требования](product.md)
- [Целевая архитектура и варианты аутентификации](architecture.md)
- [Модель угроз и требования безопасности](security.md)
- [Сетевые режимы и эксплуатация](operations.md)
- [Разработка, сборка и статус реализации](development.md)

## Принципы чтения

- **Цель** — желаемое поведение продукта.
- **Требование** — условие, которому должна соответствовать реализация.
- **Предлагаемое решение** — направление проектирования, которое нужно подтвердить при реализации.
- **Не реализовано** — возможности нет в текущем коде.

Перед выпуском продукта нужно дополнить документацию фактическими схемами компонентов, спецификацией протокола, настройками сборки и проверенными процедурами восстановления.
